# open-banking.io agent skills

Agent-consumable skill manifests for working with the
[open-banking.io](https://open-banking.io) PSD2 API (EU/UK bank accounts,
balances and transactions — API key, no eIDAS certificates).

- [`skills/open-banking-io/SKILL.md`](skills/open-banking-io/SKILL.md) — core
  bank-data skill (balances, transactions, consent health)
- Tool access: [open-banking-io/mcp-server](https://github.com/open-banking-io/mcp-server)
  (Model Context Protocol, read-only)

Format follows the `skills/<vendor>/SKILL.md` convention used by agent skill
registries. MIT licensed.
